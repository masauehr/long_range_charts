# long_range_charts（1か月以上の長期予報用 天気図）

詳しくは [long-range-charts.md](long-range-charts.md) を参照。

## 目的
**1か月予報・3か月予報・暖候期/寒候期予報**など、**1か月以上先**の見通しの判断に使う図（アンサンブル/季節予報の週平均・月平均・3か月平均の**平年偏差**と**確率**、海面水温・循環指標）を作る。
週間〜2週間（〜15日先）の図は別プロジェクト [week_forecast_charts](../week_forecast_charts/)（旧名 week_to_season_charts）で扱う。**このプロジェクトは 2026-11-14 に、そこから長期予報の部分を分離して始めた。**

## 週間〜2週間の図との違い
| 項目 | week_forecast_charts（〜15日） | long_range_charts（1か月〜） |
|---|---|---|
| 予測の性格 | 初期値の影響が強い（天気の予報） | 初期値の影響は薄れ、**海面水温・大気の大規模パターンの持続性**が効く（統計的な傾向） |
| 平年偏差の基準 | 再解析の平年値でもおおむね可 | **モデル自身の気候値（過去予報=ハインドキャスト）からの偏差**が必須（モデルのバイアスが信号より大きいことがある） |
| 見せ方 | 平均・スパゲッティ・確率 | 週平均/月平均/3か月平均の偏差・**三分位（高い/平年並/低い）確率**・SST・循環指標 |
| 注意 | 天気図としても読める | 「その期間の平均的な傾向」のみ。個々の日の天気は読めない |

## 作る図の候補（詳細は [CHARTS.md](CHARTS.md)）
1. 週平均（第1〜4週）の平年偏差：500hPa高度・850hPa気温・降水
2. 月平均・3か月平均の偏差と三分位確率：気温・降水
3. 海面水温偏差（エルニーニョ/ラニーニャ、NINO3.4 の予測）
4. 循環指標：AO・NAO・PNA・MJO・ブロッキング・極渦
5. 気象庁の公式の長期予報（1か月・3か月・暖寒候期）との**併記**（参考。公式情報は JMA MCP から出典つきで）
